Gezien & favorieten synchroniseren

Markeringen worden altijd in deze browser bewaard. Met een GitHub-token worden ze ook opgeslagen in de repo (bestand state.json op branch user-state), zodat je ze op al je apparaten ziet.

  1. Open GitHub → Fine-grained token aanmaken.
  2. Repository access: Only select repositories → marktplaats-tracker.
  3. Permissions → Repository → Contents: Read and write. Verder niets.
  4. Kies een vervaldatum, maak het token en plak het hieronder (per apparaat één keer).

Let op: de repo is openbaar, dus je lijst met gezien/favorieten ook. Het token zelf blijft alleen in deze browser.
