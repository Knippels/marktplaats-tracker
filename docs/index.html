Interessant, gezien en tabbladen

Je markeringen (interessant en gezien) worden altijd in deze browser bewaard. Met een GitHub-token worden ze ook opgeslagen in de repo (bestand state.json op branch user-state), zodat je ze op al je apparaten ziet. Hetzelfde token laat je ook tabbladen toevoegen, bewerken en verwijderen (dat past config.yml aan).

  1. Open GitHub → Fine-grained token aanmaken.
  2. Repository access: Only select repositories → marktplaats-tracker.
  3. Permissions → Repository → Contents: Read and write. Verder niets.
  4. Kies een vervaldatum, maak het token en plak het hieronder (per apparaat één keer).

Let op: de repo is openbaar, dus je lijst met interessant en gezien ook. Het token zelf blijft alleen in deze browser.
